# Pravega

Fast, encrypted file transfer that combines your networks (Wi-Fi, USB-tethered phone, Ethernet) into one.

Pravega is **freeware**: free to use, not open source. This repository contains only the
release files (installer and update data). Download the latest `.dmg` from
[Releases](../../releases/latest). The app checks here for updates when it opens.

See `LICENSE` for the terms.
